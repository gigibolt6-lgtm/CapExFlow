# 設備導入稟議作成アプリ PDF出力仕様書

## 1. 現行Excelフォーマットの尊重
本アプリのPDF出力は、既存のExcel稟議書シートのレイアウト、項目順、視認性をベースとする。

## 2. 全体構成（セクション順）
1. **ヘッダー**: 承認印欄（作成・確認・承認）、稟議番号、日付、起案部署。
2. **稟議内容**: 目的、背景、現状の課題を文章形式で出力。
3. **成果**: 定性的成果、生産対象部品リスト。
4. **投資回収サマリー**: 主要指標（投資額、回収期間、IRR等）と効果内訳。
5. **推進レイアウト**: 配置図（将来）と期間・工事スケジュール。
6. **課題と対策**: 表形式で出力。
7. **設備詳細**: 既存設備との比較表、仕様明細。
8. **付録（任意）**: 詳細グラフ、計算基礎データ。

## 3. 非表示ルール（重要）
以下の条件に合致する場合、PDF上には一切表示しない。

- **空の見出し**: その見出しに紐づく項目が全て未入力の場合、見出し自体を消す。
- **空の表**: 行データが1件もない表は枠組みごと非表示。
- **未入力項目**:
  - ラベル（例：『消費電力』）と値の両方を非表示にし、詰めチャート/詰めリストにする。
  - 値が `0` の場合は、ユーザーが意図して入力した可能性があるため出力する。
- **不完全な文章**: テンプレート文章内で変数が未指定の場合は、その一節を表示しない。

## 4. セクション別の表示条件
| セクション | 表示条件 |
| :--- | :--- |
| 投資回収 | 投資総額または効果額のいずれかが入力されていること |
| 損益分岐点 | BEP計算に必要な全項目（売価、変動費等）が入力されていること |
| グラフ | グラフ描画に必要な配列データが存在すること |
| 比較表 | 比較対象（他社機など）が入力されていること |

## 5. デザイン・フォント
- **フォント**: MS P明朝 または IPA明朝系（業務書類としてのフォーマルさ）。
- **強調**: 数値指標（回収年数など）は太字または少し大きなフォントサイズで出力。
- **改ページ**: セクションの途中で不自然に切れないよう、適切な位置で改ページを挿入するロジックを検討。

## 6. ユニット別明細の出力
案件全体サマリーの後に、必要に応じて各ユニットごとの内訳ページを出力できるオプションを設ける。
- デフォルト: 全体集計のみ
- 詳細モード: ユニットごとの個別投資・効果表を添付
