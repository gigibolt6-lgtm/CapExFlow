# 設備導入稟議作成アプリ 計算仕様書

## 1. 投資金額 (Investment)
以下の項目の総和を投資総額とする。
- 設備本体費用
- 設計・エンジニアリング費用
- 加工・製作費用
- 施工・据付費用
- 輸送・保険費用
- 予備品・初期消耗品
- その他付帯費用

## 2. 効果金額 (Effect/Benefit)
「現状（投資前）」と「計画（投資後）」の差分を算出する。
- **直接効果**: 人件費削減、材料歩留向上、電力費削減。
- **間接効果**: メンテナンス費低減、品質不良削減額。
- **性能向上**: サイクルタイム短縮による増産利益。

## 3. 労務費差異 (Labor Cost Variance)
- **計算式**:
  - `生産時間 = 生産数 / 生産速度`
  - `労務費 = 生産時間 * 生産人数 * 賃率`
- **差異**: `投資前労務費 - 投資後労務費`

## 4. 投資回収指標 (Recovery Indicators)
- **投資回収年数**: `投資総額 / 年間効果額`
- **NPV (正味現在価値)**:
  - `NPV = Σ [ CF_t / (1 + r)^t ] - 投資額`
  - ※ r: 割引率, t: 年数
- **IRR (内部収益率)**: `NPV = 0` となる割引率 $r$。
- **ROI (投資利益率)**: `(年間利益 / 投資額) * 100`

## 5. 損益分岐点 (Break-Even Point)
- **変動費項目**: 材料費、電力費、直接労務費（可変分）。
- **固定費項目**: 設備減価償却費、メンテナンス費（固定分）、間接費。
- **限界利益**: `売価 - 変動費`
- **損益分岐点販売数**: `固定費 / 限界利益`
- **損益分岐点稼働率**: `損益分岐点販売数 / 最大生産能力`

## 6. 複数ユニットの集計ルール
1つの案件に複数ユニットがある場合の統合ロジック。

| 項目 | 集計方法 | 備考 |
| :--- | :--- | :--- |
| 投資総額 | 単純合計 | $\sum$ Unit Investments |
| 効果総額 | 単純合計 | $\sum$ Unit Effects |
| 投資回収年数 | **再計算** | $\text{Total Investment} / \text{Total Annual Effect}$ |
| NPV | 単純合計 | 各ユニットのNPVの総和 |
| IRR | **再計算** | 全ユニットを合算したキャッシュフロー系列から算出 |
| ROI | **再計算** | $\text{Total Annual Profit} / \text{Total Investment}$ |
| BEP稼働率 | **再計算** | 合算した固定費と限界利益から算出 |

## 7. 注意点
- **会社標準**: 割引率や耐用年数は設定画面(Settings)から変更可能とし、デフォルト値を設定する。
- **端数処理**: 金額は円単位、年数は小数第2位で四捨五入を基本とする。
