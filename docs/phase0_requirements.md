# 設備導入稟議作成アプリ Phase 0 要件定義書

## 1. アプリの目的
設備導入における稟議書作成業務を標準化・効率化し、精度の高い投資判断（投資回収、損益分岐点、NPV、IRR等）を迅速に行えるようにすることを目的とする。

## 2. 現行Excelの課題
- **属人化**: 作成者によって数式やフォーマットが微妙に異なり、集計や比較が困難。
- **複雑性**: 複数設備や複数ラインが絡む案件では、損益分岐点や労務費の計算が非常に複雑になり、ミスが発生しやすい。
- **出力の不自然さ**: 項目が未入力でも見出しや空の表が残り、PDF化した際に見栄えが悪い。
- **再利用性**: 過去案件のデータがExcelファイルとして散在しており、検索や比較ができない。

## 3. 解決したい業務課題
- 投資回収計算の標準化（NPV, IRR, ROIの正確な算出）。
- 複数ユニット（設備・工程）を統合した案件全体の収支可視化。
- 入力漏れや矛盾の早期発見。
- 提出用フォーマット（PDF）の自動生成による「清書」時間の削減。

## 4. 業務要件
- ユーザーは案件ごとに基本情報、投資内容、効果、計算ユニットを入力する。
- 複雑な案件は複数の「計算ユニット」に分割して管理し、最終的に案件全体として統合する。
- 提出前にウェブ上で計算結果（グラフ含む）を確認し、整合性をチェックする。
- PDF出力。

## 5. 利用者要件
- 現場の生産技術担当者（入力・計算）。
- 経営層・上長（PDFによる内容確認・承認判断）。
- 管理部門（投資実績のデータ管理）。

## 6. 機能要件
| カテゴリ | 機能名 | 説明 |
| :--- | :--- | :--- |
| 案件管理 | 案件一覧・検索 | 登録済み案件の閲覧。 |
| | 案件新規作成・複製 | 過去案件をベースにした作成。 |
| 入力・計算 | 基本情報管理 | 目的、背景、期限などの属性入力。 |
| | 計算ユニット管理 | 設備・ライン別の投資・効果入力。 |
| | 投資回収計算 | NPV, IRR, ROI, 回収期間の自動算出。 |
| | 損益分岐点分析 | 稼働率や単価に基づくBEP計算。 |
| | 労務費差異分析 | 導入前後の工数差異、コスト低減額の算出。 |
| 出力 | PDFプレビュー・出力 | 未入力項目を自動除外した稟議書生成。 |
| | グラフ生成 | 入力値に基づく投資内訳、CF、BEPグラフ。 |

## 7. 非機能要件
- **データ保存**: 1つのJSONファイル（projects.json）で案件情報を一括管理する。
- **実行環境**: ローカルPC上での動作。
- **UI/UX**: 入力項目はフル装備とするが、操作感を損なわないようタブ分割等で整理する。
- **信頼性**: 計算式は社内標準に基づく（未定箇所は確認を要する）。

## 8. 対象外範囲
- ワークフロー機能（承認・却下等のステータス遷移自体は本アプリ外）。
- 外部ERP・会計システムとの自動リアルタイム連携。
- 多言語対応（第一弾は日本語のみ）。

## 9. 前提条件
- ユーザーは最新のWebブラウザを使用できる環境にある。
- PDF出力には特定のテンプレート（現行Excel踏襲）を使用する。

## 10. 用語定義
- **計算ユニット**: 1つの稟議案を構成する独立した投資単位（例：搬送ロボット、プレス機など）。
- **NPV (正味現在価値)**: 投資から得られるCFの現在価値から投資額を引いたもの。
- **IRR (内部収益率)**: 投資の効率性を示す指標。
- **BEP (損益分岐点)**: 利益がゼロになる売上高または稼働率。
