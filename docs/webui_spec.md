# 設備導入稟議作成アプリ Web UI仕様書

## 1. 画面一覧
| 画面名 | 役割 | 主な要素 |
| :--- | :--- | :--- |
| 案件一覧画面 | 登録案件の管理 | 検索窓、ステータスフィルタ、案件カード |
| 案件詳細・編集 | データの入力・確認 | タブメニュー、サマリーカード、入力フォーム |
| 設定画面 | システム共通設定 | 会社名、基準割引率、PDFテンプレート設定 |

## 2. 画面遷移
1. アプリ起動 → **案件一覧画面**
2. 「新規作成」or「編集」クリック → **案件編集画面（基本情報タブ）**
3. 各タブで入力 → 上部**サマリーカード**がリアルタイム更新
4. 「プレビュー」タブクリック → **PDFプレビュー表示**
5. 「PDF出力」ボタンクリック → PDF保存

## 3. 案件編集画面：タブ構成と入力内容
| タブ名 | 主要入力項目 | 備考 |
| :--- | :--- | :--- |
| 基本情報 | 件名、起案日、部署、ステータス | |
| 稟議内容 | 目的、背景、現状の課題、導入範囲 | |
| 成果 | 定性的効果、生産対象部品、予定生産数 | |
| 計算ユニット | ユニットの追加・編集・削除 | ユニットごとに詳細入力へ遷移またはポップアップを表示 |
| 投資回収 | NPV/IRR/ROIに関わる追加CF情報 | 全体共通の前提条件（割引率等） |
| レイアウト案 | 工程図、工場配置、工事期間 | 画像アップロード（将来） |
| 課題・対策 | リスク、対策、担当、期限 | |
| 設備詳細 | 形式、仕様、精度、速度、比較表 | |
| プレビュー | | ブラウザ上でのPDF最終出力イメージ確認 |

## 4. 計算ユニットUI
- **一覧表示**: 案件編集画面の中で、カード形式でユニットを表示。
- **詳細入力**: 以下の計算パーツをオン・オフして表示。
  - 投資内訳入力
  - 効果内訳入力
  - 労務費差異入力
  - 損益分岐点入力

## 5. サマリーカード (Sticky Header)
画面上部に固定され、入力中も常に視認可能。
- **指標**: 投資総額、投資回収年数、IRR、NPV
- **ステータス**: 入力完成度（％）、警告数

## 6. グラフ仕様
- **投資内訳**: 円グラフ（設備費・工事費・設計費等の割合）。
- **損益分岐点**: 折れ線グラフ（売上 vs 変動費+固定費）。
- **CF推移**: 棒グラフ＋積み上げグラフ（年次キャッシュフローと累積）。
- **表示条件**: 必要な最小入力項目（例：投資額と単価・数量など）が揃った時のみレンダリングする。

## 7. 入力チェック・バリデーション
- **方針**: 保存は常に可能とし、PDF出力時に「警告」を出す。
- **警告例**:
  - 「投資回収年数が10年を超えています（閾値チェック）」
  - 「損益分岐点計算に必要な『売価』が入力されていません」
  - 「IRRが負の値です」

## 9. デザイン・アクセシビリティ
- **テーマ切り替え**: 画面右上のヘッダーまたはサマリーカードに「ライト/ダークモード」切替スイッチを配置。
- **適用範囲**: アプリ全体（背景、テキスト、カード、入力フォーム、グラフ配色）にグローバルに適用。
- **保存**: ユーザーの選択したテーマはブラウザの `localStorage` または `projects.json` の設定として保存する（今回はまず localStorage 優先）。
- **コントラスト**: ダークモード時もグラフの視認性を確保するカラーパレットを採用。
